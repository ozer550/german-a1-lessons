# German A1 Lessons

22 lessons built from the teacher's notes on the class's "A1 German Simona LG" Miro board, in the same order as on the board (left to right).

Each lesson has:

- the rules and examples from the board
- English for every example (translations added for this page are shown in grey italics)
- a chapter recap with the key rules and examples
- a quick self-check quiz (tap a question to see the answer)

Student introductions and practice notes are not included.

## Open it

Download `index.html` and open it in any browser. It's a single file with no other dependencies.
